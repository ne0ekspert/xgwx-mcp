# Library-generated blank projects

`create_file` calls `libxgwx::create_project`; it does not read or embed `.xgwx`
templates. The legacy profile IDs and `list_templates` interface remain for API
compatibility. Profile SHA-256 values describe generated bytes, not source files.

Library-owned native XML parameter defaults and opaque security records are in
`libxgwx/src/project_defaults/`, with fixture provenance and hashes in its manifest.
The library assembles the gzip container, size, alignment and header checksum,
then applies guarded CPU selection and program creation for ST/IL variants.
Default names remain `NewProject`, `LSPLC`, and `NewProgram`; creation retains
library default identities and does not rewrite undocumented parameter/security
fields. The former workspace assets have been removed. Tests generate starting projects
through the library; original native compatibility fixtures remain in libxgwx.
`manifest.json` records historical provenance only.

Local generation and verified serialization do not establish native XG5000
Open → Check Program → Save As acceptance or PLC execution.
